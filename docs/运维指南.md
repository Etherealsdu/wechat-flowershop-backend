## 监控与告警

### 健康检查端点

系统提供以下健康检查端点：

| 端点 | 用途 | 返回示例 |
|------|------|----------|
| `/health` | 详细健康检查 | `{"status":"healthy","checks":{...}}` |
| `/ready` | 就绪检查 | `{"status":"ready"}` |
| `/` | 基础信息 | `{"message":"...",version":"1.0.0"}` |

### 健康检查脚本

```bash
#!/bin/bash
# /home/user/scripts/health_check.sh

API_URL="http://localhost:3000"
ALERT_WEBHOOK="https://your-webhook-url"

# 检查 API 健康状态
check_api() {
    response=$(curl -s -o /dev/null -w "%{http_code}" $API_URL/health)
    if [ "$response" != "200" ]; then
        echo "API 健康检查失败: HTTP $response"
        send_alert "API 服务异常"
        return 1
    fi
    echo "API 健康检查通过"
    return 0
}

# 检查 MySQL 连接
check_mysql() {
    if ! mysql -u flowershop -p密码 -e "SELECT 1" > /dev/null 2>&1; then
        echo "MySQL 连接失败"
        send_alert "MySQL 服务异常"
        return 1
    fi
    echo "MySQL 连接正常"
    return 0
}

# 检查 Redis 连接
check_redis() {
    if ! redis-cli ping > /dev/null 2>&1; then
        echo "Redis 连接失败"
        send_alert "Redis 服务异常"
        return 1
    fi
    echo "Redis 连接正常"
    return 0
}

# 检查磁盘空间
check_disk() {
    usage=$(df / | awk 'NR==2 {print $5}' | sed 's/%//')
    if [ "$usage" -gt 85 ]; then
        echo "磁盘使用率过高: ${usage}%"
        send_alert "磁盘空间不足: ${usage}%"
        return 1
    fi
    echo "磁盘使用率: ${usage}%"
    return 0
}

# 发送告警
send_alert() {
    message=$1
    timestamp=$(date '+%Y-%m-%d %H:%M:%S')
    curl -s -X POST $ALERT_WEBHOOK \
        -H "Content-Type: application/json" \
        -d "{\"text\":\"[告警] $message - $timestamp\"}"
}

# 执行检查
echo "=== 开始健康检查 $(date) ==="
check_api
check_mysql
check_redis
check_disk
echo "=== 健康检查完成 ==="
```

### 告警规则

```yaml
# alerts.yml
groups:
  - name: flowershop
    rules:
      # API 错误率告警
      - alert: HighErrorRate
        expr: rate(http_requests_total{status=~"5.."}[5m]) / rate(http_requests_total[5m]) > 0.05
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "API 错误率过高"
          description: "错误率超过5%: {{ $value }}"

      # 响应时间告警
      - alert: SlowResponseTime
        expr: histogram_quantile(0.95, rate(http_request_duration_seconds_bucket[5m])) > 1
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "API 响应时间过慢"
          description: "P95 响应时间超过1秒: {{ $value }}s"

      # 内存使用告警
      - alert: HighMemoryUsage
        expr: (node_memory_MemTotal_bytes - node_memory_MemAvailable_bytes) / node_memory_MemTotal_bytes > 0.9
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "内存使用率过高"
          description: "内存使用率超过90%"

      # 磁盘空间告警
      - alert: LowDiskSpace
        expr: (node_filesystem_avail_bytes / node_filesystem_size_bytes) < 0.15
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "磁盘空间不足"
          description: "可用空间不足15%"
```

```

    ├── app.log         # 应用日志
    ├── error.log       # 错误日志
    └── access.log      # 访问日志
```

```javascript

module.exports = {

    out_file: '/var/log/flowershop/app.log',
```

### 日志轮转配置

```bash
# /etc/logrotate.d/flowershop
/var/log/flowershop/*.log {
    daily
    rotate 30
    compress
    delaycompress
    missingok
    notifempty
    create 644 www-data www-data
    dateext
    dateformat -%Y%m%d
    postrotate
        pm2 reloadLogs
    endscript
}

/var/log/nginx/*.log {
    daily
    rotate 14
    compress
    delaycompress
    missingok
    notifempty
    create 644 www-data www-data
    sharedscripts
    postrotate
        nginx -s reopen
    endscript
}
```

### 日志分析命令

```bash
# 查看最近的错误日志
tail -f /var/log/flowershop/error.log

# 统计HTTP状态码
cat /var/log/nginx/access.log | awk '{print $9}' | sort | uniq -c | sort -rn

# 查找慢请求
grep "took.*ms" /var/log/flowershop/app.log | awk '$NF > 1000'

# 查看特定时间段的日志
awk '$4 >= "[04/Feb/2024:10:00" && $4 <= "[04/Feb/2024:11:00"' /var/log/nginx/access.log

# 统计访问量最高的接口
cat /var/log/nginx/access.log | awk '{print $7}' | sort | uniq -c | sort -rn | head -20
```

```nginx
# /etc/nginx/nginx.conf
```

## 安全加固

### 系统安全

```bash
# 配置防火墙
sudo ufw enable
sudo ufw allow 22/tcp    # SSH
sudo ufw allow 80/tcp    # HTTP
sudo ufw allow 443/tcp   # HTTPS
sudo ufw deny 3306/tcp   # MySQL（仅本地访问）
sudo ufw deny 6379/tcp   # Redis（仅本地访问）
sudo ufw status

# 禁用 root SSH 登录
sudo sed -i 's/PermitRootLogin yes/PermitRootLogin no/' /etc/ssh/sshd_config
sudo systemctl restart sshd

# 配置 fail2ban
sudo apt-get install fail2ban
sudo systemctl enable fail2ban
```

- [ ] JWT 密钥已使用强密码（至少32字符）

- [ ] 速率限制已启用
- [ ] HTTPS 已启用
- [ ] 敏感信息未记录在日志中
- [ ] 生产环境已禁用调试模式

## 故障排查

### 常见问题及解决方案

#### 1. API 服务无响应

```bash
# 检查 PM2 进程
pm2 status

# 查看错误日志
pm2 logs flowershop-api --err --lines 50

# 检查端口占用
sudo lsof -i :3000

# 重启服务
pm2 restart flowershop-api
```

#### 2. 数据库连接失败

```bash
# 检查 MySQL 状态
sudo systemctl status mysql

# 检查连接数
mysql -e "SHOW STATUS LIKE 'Threads_connected';"
mysql -e "SHOW PROCESSLIST;"

# 检查错误日志
sudo tail -f /var/log/mysql/error.log

# 重启 MySQL
sudo systemctl restart mysql
```

#### 3. Redis 内存不足

```bash
# 查看内存使用
redis-cli info memory

# 查看键数量
redis-cli dbsize

# 清理过期键
redis-cli --scan --pattern '*' | head -100

# 查看大键
redis-cli --bigkeys
```

#### 4. 磁盘空间不足

```bash
# 查看磁盘使用
df -h

# 查找大文件
sudo find / -type f -size +100M -exec ls -lh {} \;

# 清理日志
sudo find /var/log -name "*.log.*.gz" -mtime +30 -delete

# 清理 Docker
docker system prune -a
```

#### 5. Nginx 502 Bad Gateway

```bash
# 检查后端服务
curl localhost:3000/health

# 检查 Nginx 配置
sudo nginx -t

# 查看 Nginx 错误日志
sudo tail -f /var/log/nginx/error.log

# 重载 Nginx
sudo nginx -s reload
```
