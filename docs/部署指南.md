## 部署前准备

### 1. 获取源代码

```bash
git clone https://github.com/Etherealsdu/wechat-flowershop-backend.git
cd wechat-flowershop-backend
```

### 2. 配置环境变量

复制环境变量模板：

```bash
cp backend/.env.example backend/.env
```

编辑 `backend/.env` 文件，配置以下必要参数：

```bash
# ========== 基础配置 ==========
NODE_ENV=production
PORT=3000

# ========== 数据库配置 ==========
DB_HOST=localhost
DB_PORT=3306
DB_USER=flowershop
DB_PASSWORD=您的安全密码
DB_NAME=wechat_flowershop

# ========== Redis 配置 ==========
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=您的Redis密码

# ========== JWT 配置 ==========
# 生产环境必须修改此密钥！使用以下命令生成：
# openssl rand -base64 64
JWT_SECRET=您的JWT密钥（至少32个字符）
JWT_EXPIRES_IN=7d
JWT_REFRESH_EXPIRES_IN=30d

# ========== 微信小程序配置 ==========
WECHAT_APP_ID=您的小程序AppID
WECHAT_APP_SECRET=您的小程序AppSecret

# ========== 阿里云 OSS 配置（文件存储） ==========
ALI_OSS_REGION=oss-cn-hangzhou
ALI_OSS_ACCESS_KEY_ID=您的AccessKeyId
ALI_OSS_ACCESS_KEY_SECRET=您的AccessKeySecret
ALI_OSS_BUCKET=您的Bucket名称

# ========== 跨域配置 ==========
CORS_ORIGIN=https://your-admin-domain.com

# ========== 日志配置 ==========
LOG_LEVEL=info
```

### 3. 配置安全检查清单

在部署到生产环境前，请确认：

- [ ] `JWT_SECRET` 已修改为强密码（至少32字符）
- [ ] 数据库密码已设置为强密码
- [ ] 微信小程序 AppID 和 AppSecret 已正确配置
- [ ] 阿里云 OSS 凭证已配置（如使用文件上传功能）
- [ ] 防火墙已配置，仅开放必要端口（80, 443）
- [ ] SSL 证书已准备好

## Docker 部署（推荐）

### 1. 环境准备

安装 Docker 和 Docker Compose：

```bash
# Ubuntu/Debian
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# 安装 Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose
```

### 2. 配置 Docker Compose

创建生产环境配置文件 `.env`：

```bash
# Docker Compose 环境变量
DB_ROOT_PASSWORD=强密码_数据库root
DB_USER=flowershop
DB_PASSWORD=强密码_数据库用户
DB_NAME=wechat_flowershop
DB_PORT=3306

REDIS_PORT=6379

APP_PORT=3000
NGINX_PORT=80
```

### 3. 启动服务

```bash
# 构建并启动所有服务
docker-compose up -d --build

# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs -f app
```

### 4. 初始化数据库

```bash
# 进入应用容器
docker-compose exec app sh

# 同步数据库结构
npm run db:sync

# 初始化测试数据（可选）
npm run db:seed

# 退出容器
exit
```

### 5. 验证部署

```bash
# 检查健康状态
curl http://localhost/health

# 检查 API 响应
curl http://localhost/api/products
```

## 手动部署

### 1. 安装 Node.js

```bash
# 使用 nvm 安装（推荐）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
source ~/.bashrc
nvm install 20
nvm use 20

# 或使用 NodeSource
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
```

### 2. 安装 MySQL 8.0

```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install -y mysql-server

# 安全配置
sudo mysql_secure_installation

# 创建数据库和用户
sudo mysql -e "
CREATE DATABASE wechat_flowershop CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'flowershop'@'localhost' IDENTIFIED BY '您的强密码';
GRANT ALL PRIVILEGES ON wechat_flowershop.* TO 'flowershop'@'localhost';
FLUSH PRIVILEGES;
"
```

### 3. 安装 Redis

```bash
sudo apt-get install -y redis-server

# 配置密码（可选但推荐）
sudo sed -i 's/# requirepass foobared/requirepass 您的Redis密码/' /etc/redis/redis.conf

# 重启服务
sudo systemctl restart redis-server
sudo systemctl enable redis-server
```

### 4. 部署应用

```bash
cd wechat-flowershop-backend/backend

# 安装依赖
npm ci --production

# 同步数据库
npm run db:sync

# 使用 PM2 启动
npm install -g pm2
pm2 start server.js --name flowershop-api \
    --max-memory-restart 1G \
    --instances 2 \
    --exec-mode cluster

# 设置开机自启
pm2 startup
pm2 save
```

### 5. 配置 Nginx

创建配置文件 `/etc/nginx/sites-available/flowershop`：

```nginx
upstream flowershop_backend {
    server 127.0.0.1:3000;
    keepalive 64;
}

# HTTP 重定向到 HTTPS
server {
    listen 80;
    server_name api.your-domain.com;
    return 301 https://$server_name$request_uri;
}

# HTTPS 配置
server {
    listen 443 ssl http2;
    server_name api.your-domain.com;

    # SSL 证书
    ssl_certificate /etc/nginx/ssl/fullchain.pem;
    ssl_certificate_key /etc/nginx/ssl/privkey.pem;

    # SSL 安全配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256;
    ssl_prefer_server_ciphers off;
    ssl_session_cache shared:SSL:10m;
    ssl_session_timeout 1d;

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;

    # 请求体大小限制
    client_max_body_size 10M;

    # API 代理
    location /api {
        proxy_pass http://flowershop_backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
        proxy_read_timeout 90;
        proxy_connect_timeout 90;
    }

    # 健康检查
    location /health {
        proxy_pass http://flowershop_backend;
        access_log off;
    }

    # 就绪检查
    location /ready {
        proxy_pass http://flowershop_backend;
        access_log off;
    }
}
```

启用配置：

```bash
sudo ln -s /etc/nginx/sites-available/flowershop /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

## Kubernetes 部署

### 1. 创建命名空间

```bash
kubectl create namespace flowershop
```

### 2. 创建 Secret

```yaml
# k8s/secret.yaml
apiVersion: v1
kind: Secret
metadata:
  name: flowershop-secrets
  namespace: flowershop
type: Opaque
stringData:
  DB_PASSWORD: "您的数据库密码"
  JWT_SECRET: "您的JWT密钥"
  REDIS_PASSWORD: "您的Redis密码"
  WECHAT_APP_SECRET: "您的微信AppSecret"
  ALI_OSS_ACCESS_KEY_SECRET: "您的OSS密钥"
```

### 3. 创建 ConfigMap

```yaml
# k8s/configmap.yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: flowershop-config
  namespace: flowershop
data:
  NODE_ENV: "production"
  DB_HOST: "mysql-service"
  DB_PORT: "3306"
  DB_USER: "flowershop"
  DB_NAME: "wechat_flowershop"
  REDIS_HOST: "redis-service"
  REDIS_PORT: "6379"
  WECHAT_APP_ID: "您的微信AppID"
  ALI_OSS_REGION: "oss-cn-hangzhou"
  ALI_OSS_BUCKET: "您的Bucket"
```

### 4. 创建 Deployment

```yaml
# k8s/deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: flowershop-api
  namespace: flowershop
spec:
  replicas: 3
  selector:
    matchLabels:
      app: flowershop-api
  template:
    metadata:
      labels:
        app: flowershop-api
    spec:
      containers:
      - name: api
        image: your-registry/flowershop-backend:latest
        ports:
        - containerPort: 3000
        envFrom:
        - configMapRef:
            name: flowershop-config
        - secretRef:
            name: flowershop-secrets
        resources:
          requests:
            memory: "256Mi"
            cpu: "250m"
          limits:
            memory: "512Mi"
            cpu: "500m"
        livenessProbe:
          httpGet:
            path: /health
            port: 3000
          initialDelaySeconds: 30
          periodSeconds: 10
        readinessProbe:
          httpGet:
            path: /ready
            port: 3000
          initialDelaySeconds: 5
          periodSeconds: 5
```

### 5. 应用配置

```bash
kubectl apply -f k8s/
```

## 微信小程序配置

### 1. 服务器域名配置

登录 [微信公众平台](https://mp.weixin.qq.com)，在「开发」-「开发管理」-「开发设置」中配置：

| 类型 | 域名 |
|------|------|
| request 合法域名 | https://api.your-domain.com |
| uploadFile 合法域名 | https://api.your-domain.com |
| downloadFile 合法域名 | https://your-oss-bucket.oss-cn-hangzhou.aliyuncs.com |

### 2. 接口适配说明

本后台系统提供以下小程序端接口：

| 功能模块 | 接口前缀 | 说明 |
|----------|----------|------|
| 用户认证 | `/api/auth` | 微信登录、Token刷新 |
| 用户信息 | `/api/users/profile` | 个人信息管理 |
| 商品浏览 | `/api/products` | 商品列表、详情、搜索 |
| 购物车 | `/api/cart` | 购物车管理 |
| 收货地址 | `/api/users/addresses` | 地址管理 |
| 订单管理 | `/api/orders/my` | 用户订单 |
| 轮播图 | `/api/banners` | 首页轮播 |
| 分类 | `/api/categories` | 商品分类 |

## SSL 证书配置

### 使用 Let's Encrypt（免费）

```bash
# 安装 Certbot
sudo apt-get install -y certbot python3-certbot-nginx

# 获取证书
sudo certbot --nginx -d api.your-domain.com
```

```bash
# 添加定时任务
```

## 常见问题排查

### 1. 数据库连接失败

```bash
# 检查 MySQL 状态
sudo systemctl status mysql

# 测试连接
mysql -h localhost -u flowershop -p wechat_flowershop

# 检查防火墙
sudo ufw status
```

### 2. Redis 连接失败

```bash
# 检查 Redis 状态
sudo systemctl status redis

# 测试连接
redis-cli ping
```

### 3. 应用启动失败

```bash
# 查看 PM2 日志
pm2 logs flowershop-api

# 查看 Docker 日志
docker-compose logs app
```

### 4. Nginx 502 Bad Gateway

```bash
# 检查后端服务
curl localhost:3000/health

# 检查 Nginx 配置
sudo nginx -t

# 查看 Nginx 错误日志
sudo tail -f /var/log/nginx/error.log
```

### 5. 微信登录失败

1. 确认 AppID 和 AppSecret 配置正确
2. 确认服务器域名已在微信公众平台配置
3. 确认服务器时间准确（误差不超过5分钟）
